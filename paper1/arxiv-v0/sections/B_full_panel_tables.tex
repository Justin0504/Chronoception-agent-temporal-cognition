\paragraph{Reading the CIs.}
The headline ranking is now robust across all $n{\geq}15$ cells. Sonnet 4.6 sits closest to grounded ($+0.07$, CI just brackets zero). gpt-4o-mini and Qwen2.5-7B occupy the over-report extreme ($+1.1$ to $+1.6$, narrow CIs). \textbf{o4-mini} occupies the under-report extreme: with the Route B-1 fill its T3.1 cells are now well-powered at $n{=}39/34$ with $\rho \in [-1.54,-1.50]$, CIs $[-1.83,-1.06]$ across settings --- the under-report Hidden-Time signature is now a $> 2$ orders-of-magnitude effect at $95\%$ confidence. The \textbf{Sonnet-thinking sign-flip} is firm under Setting B (CI $[-0.30,-0.10]$, fully below zero, $n{=}15$); under Setting A it remains tentative on $n{=}9$ (CI $[-0.33,+0.21]$ brackets zero). On the wall axis the thinking variant matches base Sonnet 4.6 cell-for-cell: Setting A $0\%$ pass [Wilson $0,0.11$], Setting B $100\%$ pass [Wilson $0.88,1.00$] on $n{=}30$ each --- \textbf{reasoning-token expansion does not install date awareness through the loss}, exactly as Theorem~\ref{thm:cit} predicts. The $n{<}10$ residue (o3 T3.1 on either setting, gpt-5.1 T3.1 Setting A, Qwen2.5-7B T1.1 Setting A) reflects reasoning-model parser drops where the model declined to commit a duration; the directions of the point estimates are consistent with the larger-$n$ cells but the wide CIs forbid confident sign claims on these specific rows.

\paragraph{Per-budget $\CAR$ curves.}
Per-budget $\CAR$ values for each model appear in the supplementary data file \texttt{pilot-results/metrics.csv}. The qualitative shape across all models: $\CAR$ falls toward zero as $\budget$ increases, exactly as predicted by L2 (the agent uses a near-constant wall-clock duration regardless of budget). Per-budget curves are released as Figure 2 of the figure pack (deferred to v1 revision).

\paragraph{Trajectory release.}
All $\sim$4{,}000 trajectory JSONs are released across \texttt{pilot-results/}, \texttt{e1-results/}, \texttt{e2-results/}, \texttt{e3-results/}, and \texttt{e5-results/} in the project repository. Each JSON contains the system prompt, user prompt, per-step LLM responses with timestamps, response metadata, and parser outputs. The full dataset is approximately 600\,MB across the five directories.

\paragraph{Reasoning-panel completeness update (Route B-1).}
The Route B-1 fill brings the panel to its final state. \textbf{Sonnet 4.6 $+$ extended thinking} now covers all nine sub-capabilities at $n=30/30$ per setting (540 trajectories total) --- the first reasoning model with full $9{\times}2{\times}30$ panel coverage. \textbf{OpenAI o3} and \textbf{o4-mini} each got $n=30/30$ for T1.1, T2.3, and T3.1 across both settings (360 trajectories per model). Headline confirmations: \textbf{(i)} the wall axis (T1.1) is unchanged by reasoning-token expansion. On the same 30 instances, Sonnet 4.6 thinking matches base Sonnet 4.6 cell-for-cell: Setting~A $0\%$ pass [Wilson $0, 0.11$], Setting~B $100\%$ pass [Wilson $0.88, 1.00$]. The Injection Tell pattern is preserved across the thinking toggle. \textbf{(ii)} o3 Setting~B T1.1 reaches $100\%$ pass on $n=51$ decided trajectories [Wilson $0.93, 1.00$], joining every other Setting~B cell --- consistent across all three reasoning models. \textbf{(iii)} o4-mini T3.1 is now powered to $n=39/34$, with median $\rho \in [-1.54, -1.50]$ and CIs $[-1.83, -1.06]$ across settings --- the Hidden-Time under-report is now a $>10^{1.5}$-fold ratio at $95\%$ confidence on the cell, not a small-$n$ artefact. T3.2 and T3.3 thinking trajectories ($n=30/30 \times 4$) are released but their $\tau_\text{self}$ extraction parser was not re-run on this batch and will appear in a follow-up data release.
