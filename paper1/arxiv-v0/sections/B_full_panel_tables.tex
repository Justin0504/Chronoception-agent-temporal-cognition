\paragraph{Reading the CIs.}
The headline ranking is robust on $n\geq 15$ cells: Sonnet 4.6 closest to grounded ($+0.07$, CI just brackets zero), gpt-4o-mini and Qwen2.5-7B at the over-report extreme ($+1.1$ to $+1.6$, narrow CIs), o4-mini at the under-report extreme ($-1.54$, narrow CI). The $n<10$ cells (o3 T3.1, Sonnet thinking Setting A, three Setting A T1.1 cells) are underpowered: o3 T3.1 $\rho$ point estimate $+0.34$ has CI $[-0.65, +0.92]$, so reasoning-model L3 direction is only informative on Setting B and on o4-mini. The Sonnet-thinking sign-flip is firm under Setting B (CI $[-0.30, -0.10]$, fully below zero) but tentative under Setting A (CI $[-0.33, +0.21]$ brackets zero on $n=9$). We do not retract the Reverse-Scaling Theorem confirmation; we note that within-vendor evidence on the narrative axis rests primarily on the Setting B cell, and on the intra-model o4-mini effort sweep.

\paragraph{Per-budget $\CAR$ curves.}
Per-budget $\CAR$ values for each model appear in the supplementary data file \texttt{pilot-results/metrics.csv}. The qualitative shape across all models: $\CAR$ falls toward zero as $\budget$ increases, exactly as predicted by L2 (the agent uses a near-constant wall-clock duration regardless of budget). Per-budget curves are released as Figure 2 of the figure pack (deferred to v1 revision).

\paragraph{Trajectory release.}
All $\sim$4{,}000 trajectory JSONs are released across \texttt{pilot-results/}, \texttt{e1-results/}, \texttt{e2-results/}, \texttt{e3-results/}, and \texttt{e5-results/} in the project repository. Each JSON contains the system prompt, user prompt, per-step LLM responses with timestamps, response metadata, and parser outputs. The full dataset is approximately 600\,MB across the five directories.

\paragraph{Reasoning-panel completeness update.}
The original Sonnet 4.6 + extended thinking run carried T3.1 only ($n=30/30$). A targeted fill (Route B-1, see release notes) extended the thinking variant to the wall axis (T1.1, T1.2, T1.3) and to two step-axis caps (T2.1, T2.2), each at $n=30/30$, plus a partial T2.3 no-injection cell ($n=22$). Headline result on the wall axis: \textbf{thinking does not change L1 behaviour.} On T1.1, the with-thinking variant matches base Sonnet 4.6 to the cell --- Setting~A: $0\%$ pass ($n_{\text{decided}}=30$, Wilson 95\% CI $[0.00, 0.11]$); Setting~B: $100\%$ pass ($n_{\text{decided}}=30$, Wilson 95\% CI $[0.89, 1.00]$). The Injection Tell pattern is preserved across the thinking toggle; reasoning-token expansion does not install date awareness through the loss (consistent with Theorem~\ref{thm:cit}). Step-axis ($\CAR$) and T2.3 with-injection / T3.2 / T3.3 cells were not completed before the per-vendor API credit ceiling was reached; the raw trajectories for T1.x/T2.1/T2.2 are released for downstream re-parsing.
